Project Architecture & Technical Specification

College-Level Cybersecurity and Machine Learning Capstone System.

1. Threat Intelligence Pipeline

PhishGuard AI analyzes URLs without relying on paid external APIs. Features are extracted locally and mathematically evaluated across 20 dimensions:

  • Lexical Features: URL length, domain length, character entropy, digit density, longest token length.
  • Structural Features: Dot counts, hyphens, slashes, subdomains, @ symbols, double slash redirects.
  • Security & Domain Heuristics: Bare IP hostnames, non-standard ports, suspicious TLDs (.xyz, .top, .buzz), Punycode homographs, HTTPS status.

2. Random Forest Model

Ensemble classification using 100 decision trees (`max_depth=15`) trained on a balanced benchmark dataset of legitimate and real-world phishing attack archetypes.

  • Captures non-linear feature interactions (e.g. sensitive brand keywords paired with abuse TLDs).
  • Outputs calibrated probabilities $P(\text{Phishing})$ scaled to a 0–100 integer risk score.
  • Sub-millisecond inference latency on standard commodity CPUs.

3. Explainable Risk Assessment

Cybersecurity systems must never be black boxes. PhishGuard AI pairs model inference with explicit diagnostic reasoning:

  • Identifies and categorizes specific triggers with severity ratings (HIGH, MEDIUM, LOW).
  • Provides clear explanations for end-users to understand why a website is hazardous.
  • Adheres to ethical cybersecurity practices: risk estimates, never definite safety claims.
